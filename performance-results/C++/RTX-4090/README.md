# GeForce RTX 4090 — C++ host snapshots

CPU **`cuda-bench/C++`** timings captured on a host with an **NVIDIA GeForce RTX 4090** (same class as [**`../../CUDA/RTX-4090/README.md`**](../../CUDA/RTX-4090/README.md)).

Place **`results.csv`** here (usually by copying **`cuda-bench/results/results_cpp.csv`** after a full C++ run on that pod), then:

```bash
cd performance-results/C++/RTX-4090
python3 ../format_tables.py
```

See [**`../README.md`**](../README.md) for the full workflow.
