# Performance snapshots

Each subdirectory holds a **`results.csv`** from a full **`cuda-bench`** run (`cuda-bench/scripts/run_all.sh`) on a specific GPU, plus a **`consolidated.md`** summary generated by **`format_tables.py`**.

| Directory | GPU |
| --- | --- |
| [**`RTX-A4000/`**](RTX-A4000/README.md) | **RTX A4000** (`sm_86`) — CSV `NVIDIA RTX A4000` |
| [**`RTX-4090/`**](RTX-4090/README.md) | **GeForce RTX 4090** (`sm_89`) — CSV `NVIDIA GeForce RTX 4090` |
| [**`H100-80GB-HBM3/`**](H100-80GB-HBM3/README.md) | **H100 SXM** 80 GB HBM3 (`sm_90`) — CSV `NVIDIA H100 80GB HBM3` |

## Regenerating `consolidated.md`

From the snapshot directory that contains **`results.csv`**:

```bash
cd performance-results/RTX-A4000   # or RTX-4090 / H100-80GB-HBM3
python3 format_tables.py
```

Optional paths:

```bash
python3 format_tables.py --input results.csv --output consolidated.md
```
